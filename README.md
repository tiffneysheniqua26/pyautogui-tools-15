# pyautogui-tools-15

A powerful and lightweight autoclicker built on Python's pyautogui library, designed to simplify repetitive mouse clicking tasks. Whether you're testing applications or gaming, pyautogui-tools-15 can enhance your productivity and efficiency with customizable clicking patterns and timings.

## Features
- **Custom Click Rate**: Set precise intervals for clicks to suit your specific needs, from rapid clicks to deliberate pauses.
- **Click Patterns**: Define distinct patterns of clicks (left, right, double) to automate complex interactions in applications.
- **Hotkey Support**: Easily start and stop the autoclicker using customizable keyboard shortcuts for seamless control during usage.
- **User-Friendly Interface**: A simple command-line interface allows users to configure settings quickly without the need for extensive programming knowledge.

## Installation

To get started with pyautogui-tools-15, clone the repository and install the required packages by running the following commands in your terminal:

```bash
git clone https://github.com/YourUsername/pyautogui-tools-15.git
cd pyautogui-tools-15
pip install -r requirements.txt
```

Ensure you have Python 3.x and pip installed on your system for a smooth installation process.

## Basic Usage Example

To start using the autoclicker, navigate to the project directory and run the script with the desired parameters:

```bash
python autoclicker.py --clicks 100 --interval 0.1
```

This command configures the autoclicker to click 100 times with a 0.1-second interval between each click. You can customize the number of clicks and the interval as needed.
